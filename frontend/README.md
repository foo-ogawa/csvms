# CSVMS Frontend

CSVMS のフロントエンドアプリケーション（モック版）

## 技術スタック

- **フレームワーク**: React 18
- **ビルドツール**: Vite 5
- **言語**: TypeScript 5
- **UIライブラリ**: Ant Design 5
- **フォーム**: React Hook Form 7
- **バリデーション**: Zod 3
- **ルーティング**: React Router 6
- **状態管理**: Zustand 4
- **仮想スクロール**: @tanstack/react-virtual 3

## セットアップ

```bash
# 依存関係のインストール
npm install

# 開発サーバーの起動
npm run dev

# ビルド
npm run build
```

## ディレクトリ構成

```
src/
├── main.tsx              # エントリーポイント
├── App.tsx               # ルートコンポーネント
├── routes.tsx            # ルーティング定義
├── api/                  # API通信層（将来実装）
├── components/           # 共通コンポーネント
│   ├── Layout/           # レイアウトコンポーネント
│   ├── DataList/         # データ一覧コンポーネント
│   ├── Form/             # フォームコンポーネント
│   └── SchemaViewer/     # スキーマ表示コンポーネント
├── features/             # 機能別モジュール
│   ├── home/             # ホーム画面
│   └── dataset/          # データセット編集画面
├── mocks/                # モックデータ
├── stores/               # Zustand stores
├── types/                # 型定義
└── styles/               # スタイル
```

## 機能

### 実装済み機能

- ✅ 3カラムレイアウト（サイドバー | データ一覧 | 詳細パネル）
- ✅ サイドバーの折りたたみ
- ✅ ホーム画面（Config表示、Dataset一覧）
- ✅ データ一覧のテーブル表示
- ✅ データ一覧のタイル表示
- ✅ 仮想スクロール（大量データ対応）
- ✅ クイック検索
- ✅ ソート機能
- ✅ 行の選択・編集
- ✅ 動的フォーム生成
- ✅ 各種フィールドウィジェット
- ✅ スキーマ仕様表示
- ✅ 行の追加（先頭/末尾/前後に挿入）
- ✅ 行の複製・削除
- ✅ 未保存警告
- ✅ 変更追跡

### モックデータ

このモック版では、以下の3つのサンプルデータセットが含まれています：

1. **商品マスタ** (150行) - 商品ID、名前、カテゴリ、価格、ステータス等
2. **カテゴリ** (25行) - カテゴリID、名前、親カテゴリ、表示順等
3. **ユーザー** (500行) - ユーザーID、メール、名前、ロール、状態等

## 画面仕様

### ホーム画面 (`/`)

- Config設定のプレビュー表示
- Dataset一覧カード表示
- 各Datasetの件数・エラー数表示

### データセット編集画面 (`/datasets/:id`)

- 左: データ一覧（テーブル/タイル切替）
- 右: 編集フォーム or スキーマ表示

## 開発

# 開発サーバー起動（ホットリロード対応）
npm run dev

# TypeScriptチェック + ビルド
npm run build

# ビルド結果のプレビュー
